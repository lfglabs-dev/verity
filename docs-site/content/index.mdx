## What gets checked?

Take a function with `require(value > 7)`. Does it revert for seven and return eight for eight? The [Solidity quickstart](/solidity-import) starts with the original source, imports just that function and shows where to write the theorem. If a function or a helper it calls uses a construct the importer cannot model, the import stops.

**A successful import is not a proof.** Lean checks the property you state about the model, not equivalence to deployed bytecode. Starting from scratch instead? The [native authoring tutorial](/first-contract) takes you from a new contract to its first proof.

For compiler guarantees, see the [trust model](/trust-model) and `Compiler/Proofs/IRGeneration/Contract.lean` (generic whole-contract `CompilationModel -> IR` theorem for the current supported fragment).
